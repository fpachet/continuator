# Experiments

Use this directory for scratch scripts while trying new ideas.

Put private, large, or temporary input data under `data/local/`.
Put generated outputs under `data/generated/`.
Promote useful scripts to `examples/`, `ctor/`, or `tests/` when they become part of the project.

Current local experiment groups:

- `local_data/`: scripts that depend on private or bulky files in `data/local/`.
- `midi/`: one-off MIDI generation sketches and rendered outputs.
